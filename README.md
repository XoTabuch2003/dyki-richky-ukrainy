# Дикі річки України

Авторський веб-застосунок (PWA) про природне багатство українських водойм, риб, екосистеми та польові дослідження.

## Як користуватися

1. Відкрийте `index.html` у браузері (або запустіть локальний сервер).
2. Для встановлення на телефон: відкрийте в Chrome/Safari → «Додати на головний екран» (PWA).
3. **Режим куратора**: Налаштування → введіть PIN `1234` → Увійти.
4. У режимі куратора можна:
   - Створювати статті за шаблонами (риба / річка / рослинність / інші тварини)
   - Редагувати / видаляти статті
   - Додавати / змінювати теми з іконками
   - Змінювати банер (обкладинку) сайту
   - Вказувати геолокацію (пошук, поточне місце, клік по карті)
   - Експортувати / імпортувати всі дані як JSON

## Структура статті про риб (з блокнота)

- Вступ
- 1. Морфологічні ознаки
- 2. Спосіб життя та екологія (Біотоп)
- 3. Живлення
- 4. Розмноження та нерест

Плюс: водний ресурс, період, погода, геопозиція, фото, тематики.

## Мапа

На головній — інтерактивна мапа України з маркерами досліджень (іконки залежать від теми статті).

## Хостинг без ручного репозиторію

- Завантажте всю папку `site` на [Netlify Drop](https://app.netlify.com/drop) або [tiiny.host](https://tiiny.host) — отримаєте посилання одразу.
- Або GitHub Pages / Vercel / Cloudflare Pages.
- Щоб оновити контент для всіх: експортуйте JSON у Налаштуваннях, надішліть мені (або оновіть код), або зберігайте дані локально на своєму пристрої.

Дані зберігаються в `localStorage` браузера. Для спільного доступу до свіжих статей між пристроями використовуйте експорт/імпорт JSON або додайте backend (Supabase / Firebase) пізніше.
